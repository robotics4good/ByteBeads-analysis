## What this project is
Computational-thinking (CT) intervention at Southwest Middle School. n=30 students,
grades 7-8, one intact class, **no control group**. Students played the Byte Beads game
between a Bebras pretest and posttest. Analysis repo:
`github.com/robotics4good/ByteBeads-analysis`.

## Data
- **Distal** — Bebras CT test, 5 scored items (Q1-Q5), at three times:
  - pre (Apr 30): Q1-Q5
  - post (May 7): Q1-Q5 **identical** to pre + novel Q6 (Fast Laundry)
  - delayed (May 14): Q1-Q5 **parallel form** + novel Q6 (Making a Necklace)
- **Proximal** — in-game Day 2 task (May 5): Part A objective (partA_total 0-3),
  Part B Action Card log (coded: cs_idea_code, cs_link 0/1/2), Part C Spinner log (length_valid).
- File: `data/byte_beads_data.json`, nested per student. Codes: `"absent"`,
  `"no_response"`, `null` — none count as correct. Totals = count of items scored 1.

## What's been done
- CSV -> structured JSON conversion (30 students).
- EDA: sample/missingness, total distributions, item accuracy by phase, novel probes,
  proximal distributions + coding frequencies.
- Statistics: KR-20 reliability, paired pre->post t + Wilcoxon + dz + CI, delayed comparisons
  (caveated), item-level McNemar with Holm, proximal->gain Spearman.

## Key findings
- **Pre -> Post total:** +0.58, t=2.38, p=.026 (Wilcoxon p=.027), Cohen dz=0.47,
  95% CI [0.08, 1.08]. Real but modest; partly retest (identical items).
- **Item accuracy by phase** (% correct of valid responses):
  Q1 67/88/3 · Q2 100/92/100 · Q3 96/96/11 · Q4 17/48/0 · Q5 50/60/79.
- **Proximal -> gain:** partA_total vs gain_post_pre Spearman rho=-0.16, p=.44 (weak/null).
- KR-20 (pre) = 0.63.

## Fixed limitations (must appear in any writeup)
1. Q1-Q5 identical pre->post -> gains blend learning with practice/retest. Novel Q6 is the
   cleaner transfer signal.
2. **Delayed parallel form is NOT validated as equivalent.** Delayed accuracy collapses on
   Q1/Q3/Q4 (floor) while Q2 stays 100% and Q5 rises -> item-difficulty artifact, NOT forgetting.
   Do not interpret delayed scores as retention.
3. n=30, one class, no control -> descriptive/exploratory, not causal.

## Statistical approach (why these tests)
Paired design + small n + bounded discrete/binary data -> paired t with Wilcoxon backup and
effect sizes; McNemar (Holm-corrected) per binary item; Spearman for ordinal proximal->gain;
KR-20 for scale reliability. Avoid parametric RM-ANOVA across all three timepoints because the
delayed form is confounded; Friedman is the non-parametric omnibus if needed, still caveated.
